About ZMCL

ZMCL is an independent desktop launcher for Minecraft: Java Edition. It lets players install game versions, manage separate instances, and launch the game.

ZMCL 是一个独立开发的 Minecraft Java 版桌面启动器，可用于安装游戏版本、管理实例和启动游戏。

Microsoft Sign-in

ZMCL is applying for access to Minecraft Java game services. Microsoft sign-in lets the launcher verify a player's Java Edition entitlement and load their Minecraft profile before starting the game.

Players sign in on Microsoft's website using their web browser or a device code from the launcher.
