# Zero Minecraft Launcher (ZMCL)

ZMCL is an independent desktop launcher for Minecraft: Java Edition. It installs game versions, manages separate instances, and launches the game.

ZMCL is applying for access to Minecraft Java game services to support Microsoft sign-in, verify Java Edition entitlement, and load the player's Minecraft profile. Players sign in on Microsoft's website.

The project page is a single static HTML file. Open [index.html](index.html) in a browser to view it.
